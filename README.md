# TEDxVictoriaPeak Finance Portal

Mobile-first finance portal for the TEDxVictoriaPeak 2027 organizing committee.
Free stack: **Supabase** (database, login, receipt storage) + **GitHub Pages** (hosting).

## What it does
- **Public, no login:** dashboard (cash, net funds, budget use, sponsorship), approved transactions, submit expenses and income (they wait in Pending).
- **Organizer Login** and **Project Lead Login:** approve, edit set-up data, reports. The Head of Finance and Finance Officer are Project Lead accounts with extra finance rights.
- **Approval flow:** Project Lead → Head of Finance → Organizer (above the sign-off limit). Nobody approves their own entry.
- **Delete rules:** anything not yet in the books (pending/returned/rejected entries, unused divisions, categories, sponsors and money accounts, wrong receipts, reconciliation checks) can be deleted; posted entries can only be voided. Every delete is in the Activity log.
- **Accounting:** automatic double-entry journals, reimbursements and supplier payables, sponsor receivables, in-kind sponsorship, deposits, cash advances, transfers, opening balances, bank reconciliation, month-end close, void with reversal, full audit log.
- **Reports:** Income & Expenditure, Statement of Financial Position, Cash flow, Budget vs Actual, outstanding payables, General ledger, Trial balance. Export to CSV (Excel) or print to PDF.
- **Financial Report Pack:** one-click .xlsx with 13 formula-driven tabs (cover with sign-off, statements, budget vs actual, trial balance, payables aging, sponsors, full journal). The same pack can live in Google Sheets and refresh daily via `google-sheets/Code.gs`.

## Files
- `supabase/setup.sql` – run once in Supabase SQL Editor.
- `supabase/reset-data.sql` – clears test transactions before go-live.
- `.github/workflows/deploy.yml` – builds and publishes the site on every push.
- `.github/workflows/keep-alive.yml` – daily ping so the free Supabase project never pauses.
- `supabase/update-1-google-sheets.sql` – only for databases set up before the report pack existed.
- `supabase/update-2-delete.sql` – adds the Delete buttons' database rules to databases set up before they existed.
- `google-sheets/Code.gs` – Apps Script for the auto-refreshing Google Sheet (generated by `node scripts/build-gs.mjs` from `src/lib/pack.js`).
- `setup/` – copies of the two workflow files, for manual creation in the GitHub web editor.
- `src/` – the React app.

## Setup
See **PANDUAN-SETUP.md** (step-by-step, Bahasa Indonesia).

Repository secrets needed: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (the anon/publishable key, never the service role key).

## Security model
All rules are enforced in the database (Row Level Security and security-definer functions), not only in the browser. The public can read only aggregated, name-free data and can only create Pending entries. Receipts are in a private bucket readable only by logged-in team members.
